# Nightmare Discourse Bench

This repository contains the data, code, and supporting materials for **Nightmare Discourse Bench**, a benchmark dataset designed for testing and training direct discourse identification pipelines in computational literary studies.

The benchmark is described in the following paper:

> Carroll, Claudia, Gabi Kirilloff, and Dashiell Leigh. "NightmareDiscourseBench: A Benchmark Dataset for Fictional Direct Discourse Identification Pipelines." *Computational Humanities Research 2027*, Vol. X. *Anthology of Computers and the Humanities*, 2027, pp. X. **(Forthcoming)**

## Repository Contents

### [Benchmark Data](benchmark/)

The `benchmark/` directory contains the benchmark dataset, including the original text samples, annotation guidelines, raw annotations, and finalized benchmark data. Instructions for using the benchmark are also provided.

### [Pipeline Tests](pipeline_tests/)

The `pipeline_tests/` directory contains the data, code, and instructions necessary to replicate the accuracy test results reported in *"NightmareDiscourseBench: A Benchmark Dataset for Fictional Direct Discourse Identification Pipelines."*
