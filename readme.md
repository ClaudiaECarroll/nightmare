This repo contains the data, code and other materials to use Nightmare Discourse Bench, a benchmark dataset for testing and training of  direct discourse identification pipelines in computational literary studies. The benchmark is described in the following paper:

Claudia Carroll, Gabi Kirilloff and Dashiell Leigh. "NightmareDiscourseBench: A Benchmark Dataset for Fictional Direct Discourse Identification Pipelines". Computational Humanities Research 2027,  Vol. X. Anthology of Computers and the Humanities. 2027, p. X (Forthcoming)

If you use this benchmark for research, we ask that you cite the above paper, and use the following DOI to link to the benchmark:

xxxxxx

Data and instructions for use of the benchmark are provided in the benchmark folder.

Data, code and instructions for replication of the accuracy test results provided in "NightmareDiscourseBench: A Benchmark Dataset for Fictional Direct Discourse Identification Pipelines" are provided in the pipeline_tests folder.
