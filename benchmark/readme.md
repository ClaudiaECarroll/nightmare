# Nightmare Discourse Bench: Data

This folder contains the raw and annotated text data for **Nightmare Discourse Bench**. The following files and directories are included:

1. **[manual_samples/](manual_samples/)**
   The original text samples annotated to produce the benchmark dataset.

2. **[text_metadata.tsv](text_metadata.tsv)**
   Metadata for the original texts from which the benchmark samples were drawn.

3. **[annotation_guidelines.pdf](annotation_guidelines.pdf)**
   Instructions and examples provided to project annotators.

4. **[annotations/](annotations/)**
   The original annotations produced by the project's primary annotators.

5. **[final_benchmark.tsv](final_benchmark.tsv)**
   The finalized benchmark dataset.
