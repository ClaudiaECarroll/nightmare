This folder contains the actual raw and annotated text data for Nightmare Discourse Bench. We include here:

1. manual_samples: The original sample texts annotated to produce the benchmark data. These are plain text files extracted from plain text files downloaded from project gutenberg.
2. test_metadata.csv: The metadata for the original texts from which we sampled for the benchmark. Include text title, author, year, gutenberg source ID.
3. annotation_guidlines.pdf: The instructions and examples for annotating each of our three direct discourse categories used by the project annotators.
4. annotations: The original annotations produced by the primary annotators for the projects, saved in JSON format from the annotation interface.
5. final_benchmark.csv: The final set of annotations, after expert resolution for annotator conflicts, formatting issues and restructuring into tabular format for legibility.
